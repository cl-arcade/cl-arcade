how it works

idle time is now play time.

Long tasks mean staring at a spinner. CL Arcade turns that wait into a quick run, right in the terminal, without leaving your session.

  1. install. one line.

    Paste /plugin install cl-arcade --marketplace theBliz/cl-arcade into Claude Code and answer y. No account, no config.

  2. type /arcade.

    A cabinet opens in a pane beside the chat. Click it to insert a coin (that hands it the keyboard), pick a game and a runner.

  3. play while it works.

    The top bar counts how long Claude has been at it. When Claude finishes its turn, your run pauses with a banner. Esc takes you back to the prompt.

questions

the small print.

Where does it run?

Claude Code 2.1.275 or later, in a terminal. Tested on macOS; other terminals and the desktop app should work too. Editor extensions and mobile can't host the live game, so the pane says so.

Does it slow Claude down?

Not noticeably. It adds no requests or tokens, and it only notes when Claude starts and finishes a turn: it never reads, stores, changes or sends your code, your prompts or Claude's answers. While the pane is open, the game uses a little CPU.

How do I uninstall?

/plugin uninstall cl-arcade, then /plugin marketplace remove cl-arcade. Your best score, runner and auto-open setting sit in a small file under ~/.claude/plugins/store/; delete it for a clean slate.

Why "cl"?

Claude, or command line. Both are true: it's an arcade for the terminal, built for the time Claude spends thinking.

Can I add a game?

Yes, it's MIT-licensed. The whole engine is one file, hooks/game.ts. Pull requests welcome on GitHub.
